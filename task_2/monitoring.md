### Мотвация:

Мониторинг необходим для слежением состояния серверной части в первую очередь и понимания силы нагрузки и своевременного реагирования и масштабирования системы
### Подход:
Для сервиса расчёта цены подойдёт метод USE
метрики:
- ресурсы - CPU и RAM - для оценки горизонтального/вертикально масштабирования
- среднее время выполнения расчёта - оценка скорости выполнения/прогнозирование времени расчёта(возможно)

Для MES + MESdb подход RED

метрики:
- RPS для operator->MES - нагрузка от пользователей
- RPS для MES->MESdb - оценка производительности 
- % CPU utilisation для MESdb - оценка производительности 
- % CPU utilisation для MES - оценка производительности 
- response time для MESdb - оценка производительности 
- response time для MES - оценка производительности 

Для магазина и CRM подход four golden rule (не первостепенно, т.к. жалоб в производительности этой части нет)

метрики:
- трафик - нагрузка от пользователей
- response time - качество работы
- коды ответов запросов (кол-во во времени) - качество/правильность работы

RabbitMQ (не первостепенно, т.к. ребит справляется с нагрузкой. в последствии, при полной работе всей системы необходимо добавить)

метрики:
- заполненность очереди - оценка производительности "ядра" системы
- кол-во и скорость поступления тасок - оценка производительности "ядра" системы
- кол-во и скорость потребления тасок - оценка производительности "ядра" системы
- ресурсы - CPU и RAM - оценка состояния 

Базы данных

метрики:
- ресурсы - CPU и RAM - оценка состояния 
- время выполнения запросов - оценка состояния 
- кол-во запросов - оценка состояния 

### План действий:
Поднять систему сбора метриг мониторинга и систему визуализации (например, промитей+графана)

Далее в первую очередь покрыть мониторингами самые тормозящие и нагруженные чатсти - MES и будущий сервис расчёта цены. За ними связанные сервисы - бдшки, очередь

В дальнейшем покрыть всю остальную систему в приоритете возникновения неисправностей (если таковые будут) или начиная со стороны клиентов (для повышения качества обслуживания)
